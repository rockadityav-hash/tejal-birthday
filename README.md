# Birthday website

Open `index.html` in a browser. Use **Change front photo** to preview a separate front image, **Add photos** to add gallery images, and **Add a video** to preview a video. Gallery uploads do not change the front photo. User-selected media previews are local to the browser session; the default front photo is included with the site.

To personalize the page, edit the friend’s name, birthday greeting, and note in `index.html`.
